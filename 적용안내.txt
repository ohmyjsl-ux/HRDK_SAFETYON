안전ON 안전신문고 디자인 개선 적용 안내 (2026-10-20)

변경: 신고 화면의 캐릭터 제거, 짧은 제목 배너, 배너에 붙은 처리 현황 요약, 절제된 색상·테두리·버튼, 모바일 상단 공간 축소.

적용 방법
1. 압축을 풀면 report.html, assets 폴더, 이 안내문이 나옵니다.
2. GitHub HRDK_SAFETYON 저장소에서 기존 index.html이 보이는 최상위 위치의 Add file → Upload files로 들어갑니다.
3. report.html과 assets 폴더를 드래그하여 같은 경로로 올립니다. 실제 교체 파일은 report.html, assets/report.css, assets/report.js, assets/report-public.js 4개입니다.
4. Commit changes로 저장하고 배포가 끝나면 안전신문고를 Ctrl+F5로 새로고침합니다.

Supabase SQL·함수·비밀설정이나 관리자 파일은 이번에 바꾸지 않습니다. 신고·사진 분석·집계·PDF 게시 기능은 기존 연결을 사용합니다. 현재 실제 사이트를 직접 배포한 상태는 아닙니다.
